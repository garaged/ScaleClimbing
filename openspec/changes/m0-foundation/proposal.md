# M0 Foundation Proposal

## Why

ScaleClimbing needs a robust base before iOS UI and audio work begin.

## What changes

- Add OpenSpec retained specs and M0 change specs.
- Add Swift package for pure music-theory logic.
- Add deterministic tests for notes, pitch classes, scales, chords, and exercise evaluation.
- Add Makefile validation commands.
- Add security/privacy baseline and manual acceptance checklist.

## Impact

Future implementation can proceed through SDD/TDD/IDD with a repeatable local and hosted quality gate.
