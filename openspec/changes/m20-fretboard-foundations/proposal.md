# M20 — Fretboard Foundations

Stack on M19 PR #21 at `9b99fad8b5a8dd98bf25e758f819cdb594c877d5`. M18–M22 are one owner manual acceptance group; retain separate draft PRs and automated gates.

## Intent
Teach learners to navigate the guitar by note identity, octave and interval rather than memorize isolated positions. Reuse M18 criteria and M19 paging, keep Free Fretboard unscored.

## Scope
One Fretboard Foundations route with six modes: any note class, exact pitch, unison, octave, directed interval and piano-to-guitar transfer. Deterministic catalog across roots and varied anchors; bounded fret windows, anchor and attempted position, audition and retry/next. Standard/Novice visual labels follow shared assistance; VoiceOver names coordinates and pitch. Add one explicit guitar foundations Learning Path skill (no automatic scoring-to-mastery transfer). Preserve old progress and routes. English/es-MX. No microphone, chord fingering, CAGED, alternate-tuning UI or new dependencies.

## Acceptance
Domain catalog reachability, signed directions, correct/incorrect and retry lock; presentation geometry, guidance, mode reset, progress compatibility, simulator UI and existing regressions. Manual acceptance deferred by owner until M22 group is implemented.
