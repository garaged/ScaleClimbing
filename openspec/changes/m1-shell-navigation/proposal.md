# M1 Shell Navigation

## Intent

Turn the M1 source-level app scaffold into an explicit navigable shell with route definitions and first-round progression for Note Hunter.

## Scope

- Add a route catalog for app destinations.
- Add a home view model and SwiftUI root view that navigates to Note Hunter.
- Add Note Hunter prompt advancement without resetting cumulative score.
- Add tests for route metadata and prompt progression.

## Non-goals

- Full generated Xcode project.
- Audio playback.
- Persistence.
- Microphone, MIDI, accounts, cloud, analytics, payments, network services, or licensed content.
