# M1 iOS Keyboard Proposal

## Why

ScaleClimbing needs a first visible iOS gameplay surface while preserving a testable, portable architecture.

## What changes

- Add component architecture governance and enforcement.
- Add a SwiftUI presentation package using MVVM.
- Add a beginner two-octave piano keyboard display model.
- Add Note Hunter view model and SwiftUI screen.
- Add an iOS app composition-root scaffold.
- Add presentation tests and M1 manual acceptance checklist.

## Impact

The app gets a first playable visual recognition loop without adding audio, network, microphone, account, payment, or cloud dependencies.
