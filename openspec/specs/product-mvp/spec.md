# Product MVP Specification

## Requirements

### Requirement: iOS-first visual and auditory music practice

ScaleClimbing SHALL provide an iOS-first learning game direction that connects visual recognition, instrument interaction, and generated listening exercises.

#### Scenario: MVP scope is clear

- **GIVEN** a contributor reviews the repository
- **WHEN** they read product and milestone documentation
- **THEN** they can identify the MVP audience, included learning modes, and deferred features

### Requirement: first vertical slice uses major and minor triads

ScaleClimbing SHALL treat major/minor triads as the first complete learning slice because they exercise visual construction, chord-quality hearing, and answer validation without microphone risk.

#### Scenario: triad slice drives early implementation

- **GIVEN** a new gameplay feature is proposed for M1
- **WHEN** it does not support note, major-triad, minor-triad, or chord-quality practice
- **THEN** it must be deferred unless it unblocks the triad slice
