# Security Policy

ScaleClimbing is pre-release. Please report security concerns through a private GitHub security advisory when available, or by contacting the repository owner directly.

## Current security posture

- Offline-first MVP direction
- No account dependency
- No analytics SDK
- No microphone capture in M0
- No cloud sync in M0
- No payment implementation in M0
- Makefile security baseline check

## Supported versions

No production version is supported yet.
