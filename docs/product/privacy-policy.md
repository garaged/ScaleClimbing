# ScaleClimbing Privacy Policy

**Effective date:** November 10, 2026

ScaleClimbing is an offline-first music-learning app.

## Data

ScaleClimbing does not collect, transmit, sell, share, or track personal data. It has no account system, analytics SDK, advertising SDK, cloud sync, networked learning service, or in-app purchase flow.

Practice state and learning progress remain on the device. Generated audio is created locally. The app does not request microphone, camera, location, contacts, photo-library, notification, Bluetooth, or health access.

## External links

The app offers optional links to the open-source project, support/issues, this policy, and GitHub Sponsors. These links open only after the learner activates them and are governed by the destination’s policies.

## Changes and contact

Material privacy changes will be published in this repository before a release that uses them. For questions or concerns, open a private GitHub security advisory or an issue at https://github.com/garaged/ScaleClimbing.
