# Decision Log

## D-001 — iOS-first product direction

Accepted. Start on iOS and design the domain core for later macOS reuse.

## D-002 — Offline-first MVP

Accepted. Do not require accounts, cloud, analytics, network services, payment, or microphone capture for the MVP foundation.

## D-003 — Major/minor triad first vertical slice

Accepted. Use the triad slice to prove visual construction, generated audio, answer evaluation, and skill progression.

## D-004 — OpenSpec plus Makefile validation

Accepted. Use OpenSpec for intent and behavior, and Makefile commands for local/hosted validation parity.
