# M8 Scale Explorer — short acceptance

1. On the M8 branch, open `Apps/iOS/ScaleClimbing.xcodeproj` in an iPhone 17 simulator and open **Scale Explorer** (Scale Summit).
2. In **Explore**, confirm the initial **C Major** view highlights C–D–E–F–G–A–B, shows semitones 0,2,4,5,7,9,11, shows C major with no accidental key signature, and **Hear scale** plays a clear ascent then descent.
3. Switch to **Listen**. Play the scale; its name must remain hidden. Choose **Major** and confirm score/feedback reveal the answer once. Switch family to **Diatonic Modes** and verify the choices change and the session resets.
4. Return to **Major & Minor**, switch to **Build**, and intentionally omit B from C major. **Check scale** should play the submitted ascending attempt, report it as incomplete, and enable **Replay attempt**. Add B, check again, and confirm correct feedback.
5. Choose **A Melodic Minor** using the menus and listen: ascent should contain F♯–G♯; descent should contain G–F. Verify horizontal keyboard scrolling, legible controls and a quick VoiceOver pass.

No microphone permission, account, third-party asset or network access is expected. Automated checks cover patterns, ordered octave behavior, key metadata, generated multi-note audio, score locking, retry and iPhone navigation; this manual check focuses on audible contour and phone ergonomics.
